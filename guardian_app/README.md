# Guardian Com — Flutter-App

Dies ist der Flutter-Teil von Guardian Com (Android, Windows, Web/PWA).
Beschreibung, Setup, Builds und Architektur stehen im
[README im Projekt-Root](../README.md); Hinweise für die Entwicklung in
[CLAUDE.md](../CLAUDE.md).

Kurzüberblick:

```bash
flutter pub get
flutter run                 # Android
flutter run -d windows      # Windows
flutter build web --release # Web (Auslieferung: siehe README → Builds)
flutter test
flutter analyze
```
